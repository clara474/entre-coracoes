ENTRE CORAÇÕES — PACOTE PIX DIRETO PARA VERCEL

O QUE ESTA VERSÃO FAZ
- Mantém o quiz de quatro perguntas e o relatório premium de R$ 14,90.
- Cria uma order no Mercado Pago pela API Orders com Pix explícito:
  payment_method.id = pix; payment_method.type = bank_transfer.
- Solicita o e-mail do comprador, obrigatório nesta integração.
- Exibe o QR Code e o código Pix copia e cola no próprio site.
- Só libera o relatório após consulta autenticada do status da order no servidor.

VARIÁVEIS DE AMBIENTE NA VERCEL
1. MERCADOPAGO_ACCESS_TOKEN: Access Token privado da aplicação Mercado Pago.
2. PAYMENT_SIGNING_SECRET: chave aleatória com pelo menos 32 caracteres.
SITE_URL não é necessária nesta versão.

IMPORTANTE
- Configure as duas variáveis em Production e faça um novo deploy.
- Nunca coloque Access Token no HTML, GitHub ou mensagens.
- O e-mail informado é enviado ao Mercado Pago para criar o pagamento.
- Não é necessário inserir a chave Pix aleatória no código.
- Valide primeiro em ambiente de teste. Para receber pagamentos reais, use Access Token de produção.
- Não faça pagamento real durante a validação técnica sem confirmar que a order foi criada corretamente.

ARQUIVOS
- index.html: quiz, captura de e-mail, QR Code e cópia do Pix.
- api/create-checkout.mjs: cria a order Pix.
- api/payment-status.mjs: confirma o pagamento consultando o Mercado Pago.
- vercel.json: cabeçalhos de segurança.

LIMITES
A criação depende de credenciais válidas e da habilitação da conta no Mercado Pago. Para operação comercial mais robusta, recomenda-se complementar com Webhooks e armazenamento persistente de pedidos.
